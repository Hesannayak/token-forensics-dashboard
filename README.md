# Token Forensics Dashboard

Turn this UI into a professional looking - minimal, tech, less flashy colour, UI / UX, highly polished, professional looking site. It shouldn't look like a vibe coded site. Just create UI / UX, we don't need to build fully functional app, but design is a priority as laid out: deep layered charcoal/slate surfaces without pitch black or neon glows, clean monospace tabular alignment for contract hashes and metrics, a unified command search bar with network indicators, precision 0-100 bundle threat score gauge with muted status badges, a 3x2 forensic diagnostic grid with category point breakdowns, and an on-chain ledger table for Block-0 buyer wallets. Include both the token search home view with recent scans and the detailed token forensic report view.
